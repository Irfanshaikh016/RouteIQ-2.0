# RouteIQ 2.0 — Milestone & Phase Roadmap

## Milestone 1: Core System & Regional Foundation

### Phase 1: Project Foundation (In Progress)
- **Goal**: Full-stack scaffolding, FastAPI backend, Next.js frontend, Supabase/Postgres config, `/health` endpoint, live ping, test suite, and documentation.
- **Status**: Active execution.

### Phase 2: Road Network Graph & Ingestion
- **Goal**: NER geographic road graph representation, PostGIS node/edge schema, OSM ingestion, and graph queries.
- **Status**: Planned.

### Phase 3: Risk Assessment & Hazard Intelligence
- **Goal**: Rainfall, landslide, terrain fragility modeling, and segment risk scoring.
- **Status**: Planned.

### Phase 4: Multi-Objective Routing Engine
- **Goal**: Graph search algorithm (Fast vs. Safe vs. Balanced), alternative route generation, multi-criteria optimization.
- **Status**: Planned.

### Phase 5: Interactive GIS Dashboard & Operations Console
- **Goal**: Mapbox/Leaflet visualization, corridor hazard overlays, live dispatch monitoring, and telemetry.
- **Status**: Planned.
